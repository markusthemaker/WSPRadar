# Retained antenna-rotation walkthrough sources

- `supplied-walkthrough.en.txt` preserves the user's supplied draft byte-for-byte.
- `walkthrough.previous.en.md` and `walkthrough.previous.de.md` preserve the
  preceding website walkthroughs byte-for-byte.

The active bilingual Markdown lives one directory above. Its section markers
and reviewed resource manifest supply the shared website layout. Figure titles
and captions from the draft are rendered through the manifest; the draft's
temporary sandbox image links are replaced by native dark figures generated
from the frozen Figure 6 reconstruction.

The active text links to the current calibration walkthrough and the authors'
calibration page, uses American English spelling, and distinguishes the
archive-derived 3 dB median step and remaining 691 observations from the
publication's reception-750 boundary. The original Figure 6 comparison PDF and
imported scientific description remain available. These source archives are
not automatically copied into the public build.

The reviewed resources include an unchanged copy of the application's
`static/reference_figures/vanhamel_fig6_rotation_v1/WSPRadar_Demo_Vanhamel_Figure6.pdf`.
Its byte count and SHA-256 are recorded in the resource manifest so the
walkthrough can open the PDF directly from the static website.
